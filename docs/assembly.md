# Assembly notes

1. Press the four LED strips into the routed channels; the strip direction
   alternates so the data line snakes between rows.
2. Solder the carrier board to the strip harness before mounting it to the
   back panel. Check the 5 V rail at the test point with a dummy load.
3. Fit the acrylic diffuser last. Do not remove the protective film until the
   enclosure is closed.
4. Run the calibration sketch and record the measured colour temperature for
   the workshop log.
